# Арифметика и обработка ошибок

Интерактивные операции над двумя числами; errors, fmt.Scan и strconv. Доступные слова операций: деление, сложение, умножение, вычетание. Проверка возраста в validateAge принимает только 150; multiply и divide отклоняют также нулевой первый аргумент.

Учебная папка `basics/calc`. Код сохранён в исходном состоянии.

## Структура

- `.gitignore`
- `go.mod`
- `main.go`

## Требования и команды

Проверено на Windows с Go 1.27.1 (windows/amd64); `go.mod` требует Go 1.27.1. Команды выполняются из корня репозитория.

Точка входа: `main.go`.

```sh
go run .
```

Ввод для проверки: два числа `12`, `15`, затем слово `сложение` (каждое на отдельной строке).

```sh
go test ./...
go vet ./...
```

## Результаты проверки

- `go test ./...`: успешно (код 0).
- `go vet ./...`: успешно (код 0).
- `go run .`: успешно (код 0).

Файлов `*_test.go` нет. Успех `go test` здесь означает проверку сборки, а не прохождение набора тестов.
